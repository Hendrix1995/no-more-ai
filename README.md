# No More AI Music

YouTube 플레이리스트에서 AI로 찍어낸 음악을 찾아 큐에서 숨기고, 재생되면 다음 곡으로 건너뛰는 Chrome 확장입니다.

## 설치

Chrome 웹 스토어에는 등록되어 있지 않으므로 개발자 모드로 직접 로드합니다.

1. 이 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/Hendrix1995/no-more-ai.git
   ```
   또는 GitHub의 **Code → Download ZIP**으로 받아 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 내려받은 `no-more-ai` 폴더를 선택합니다.
5. 이미 열려 있던 YouTube 탭은 새로고침합니다.

### 업데이트

```bash
cd no-more-ai && git pull
```
그다음 `chrome://extensions`에서 확장의 새로고침 버튼을 누르고, 열린 YouTube 탭을 새로고침합니다.

## 사용법

- YouTube에서 플레이리스트를 재생하면 자동으로 동작합니다.
- AI로 판별된 곡은 플레이리스트 패널에서 사라지고, 재생 차례가 오면 다음 곡으로 넘어갑니다. 화면 왼쪽 아래에 건너뛴 이유가 잠깐 표시됩니다.
- 판정이 끝나기 전에는 재생을 잠시 멈추므로, 곡이 시작될 때 1초 안팎의 대기가 있을 수 있습니다.
- 툴바의 확장 아이콘을 누르면:
  - 켜기/끄기
  - 현재 곡의 판정 결과와 이유
  - **이 채널 차단** / **이 채널 허용**
- **설정 열기**에서 키워드, 차단·허용 채널, 판별 기준을 바꿀 수 있습니다.

## 판별 기준

하나라도 해당하면 AI 곡으로 처리합니다. 허용한 채널은 모든 기준보다 우선해 항상 재생됩니다.

| 기준 | 기본값 | 설명 |
|---|---|---|
| 차단한 채널 | 켜짐 | 팝업이나 설정에서 차단한 채널 |
| 키워드 | 켜짐 | 제목·채널명·설명·태그에 `#suno`, `udio`, `ai generated`, `ai cover`, `AI 음악` 등이 포함. "not AI generated"처럼 부정하는 문맥은 제외 |
| YouTube AI 라벨 | 켜짐 | YouTube가 붙이는 "Made with AI(AI로 제작)" 표시. 자동 더빙 표시는 제외 |
| 업로드 빈도 | 꺼짐 | 최근 7일 업로드가 기준 이상인 채널. 방송사·레이블 같은 대형 채널도 걸려 기본은 꺼 둡니다 |

## 한계

- 표시도 키워드도 없는 AI 곡은 걸러지지 않습니다. 발견하면 팝업에서 그 채널을 차단하세요.
- 사람 곡이 잘못 걸리면 팝업에서 **이 채널 허용**을 누르세요.
- 플레이리스트에서 실제로 곡을 삭제하지는 않습니다. 화면의 목록에서 숨기기만 합니다.
